# Matricular coche importado en España

Cada vez más personas traen vehículos desde Alemania, Francia, Italia y otros países europeos. Para poder circular legalmente en España, es necesario completar varios trámites administrativos antes de obtener la matrícula definitiva.

Entre los pasos más habituales están:

- ITV de importación
- pago del impuesto de matriculación
- pago del impuesto de circulación
- tramitación en la DGT
- solicitud de placas verdes temporales en algunos casos

Si necesitas más información, puedes consultar estas guías:

- [Matricular coche importado en Valencia](https://gestoriatramitesdgt.es/tramite-vehiculos/matricular-coche-importado-en-valencia/)
